# Data Structure Using Java – Stack Examples

## About This Repository

This repository contains 15 Java programming examples about the **Stack Data Structure**. These examples are prepared as coursework to demonstrate how stacks work and how they can be implemented and used in different programming situations.

## Topics Covered

The repository includes the following examples:

| Example | Description |
|---|---|
| Example 01 | Basic Stack Operations using push() |
| Example 02 | Stack Operations using peek() and pop() |
| Example 03 | Generic Stack using Java Generics |
| Example 04 | Undo Deposit using Stack |
| Example 05 | Undo Course Registration using Stack |
| Example 06 | Reversing a String using Stack |
| Example 07 | Implementing Stack using an Array |
| Example 08 | Array Stack Trace Demonstration |
| Example 09 | Empty Collection Exception |
| Example 10 | Traversing a Linked Stack |
| Example 11 | Reversing Steps using Linked Stack |
| Example 12 | Implementing Stack using Linked Nodes |
| Example 13 | Linked Stack Trace Demonstration |
| Example 14 | Undo Deposit using Linked Stack |
| Example 15 | Undo Course Registration using Linked Stack |

## Technologies Used

- Java
- IntelliJ IDEA
- Git and GitHub

## Learning Objectives

- Understand the Stack data structure.
- Learn the LIFO (Last In, First Out) principle.
- Practice push, pop, and peek operations.
- Understand array-based and linked-list-based stack implementations.
- Apply stacks to practical programming examples.
- Understand exception handling and generic programming.

## Project Structure

Each example is organized in its own package to make the source code easier to understand, organize, and run.

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open the desired Example package.
4. Run its main Java class.

## Purpose

This repository is created for educational purposes as part of a Data Structures course assignment.
